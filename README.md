## 🚀 Setup & Installation

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/downloads)
- [Visual Studio Code](https://code.visualstudio.com/) (recommended)

<details>
<summary><strong>View setup commands</strong></summary>

### 1. Clone the repository

```bash
git clone https://github.com/Dnaik03/dhanashree-portfolio.git
```

Replace the repository URL if you choose a different repository name.

### 2. Enter the project directory

```bash
cd dhanashree-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal, commonly `http://localhost:5173/`.

### 5. Build for production

```bash
npm run build
```

The production build is generated in `dist/`.

### 6. Preview the production build

```bash
npm run preview
```

Open the URL printed in the terminal to test the production build.

</details>

## 📮 Contact Form Setup

The contact form uses Formspree.

<details>
<summary><strong>Configure Formspree</strong></summary>

1. Visit [Formspree](https://formspree.io/).
2. Create a form and configure its destination email.
3. Copy the endpoint supplied by Formspree.
4. Update the `FORM_ENDPOINT` constant in the contact component.

Example placeholder:

```tsx
const FORM_ENDPOINT = 'https://formspree.io/f/YOUR_FORM_ID'
```

Replace `YOUR_FORM_ID` with the actual identifier.

### Test the form

- Submit a test message.
- Verify the success or error feedback.
- Confirm the message reaches the configured inbox or Formspree dashboard.
- Repeat the test after deployment.

**Security:** Never place email passwords, private API keys, or other secret credentials in frontend code.

</details>
